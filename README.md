# HYDROBOTICS

Static site prepared for GitHub Pages. The pages load their shared theme from
`theme.css` and site scripts from `js/`.

## Publish with GitHub Pages

In the repository's **Settings → Pages**, select **Deploy from a branch**, pick
the branch containing these files, and set the folder to **/(root)**. Save the
settings and wait for the Pages deployment to finish.

GitHub Pages serves only static files. Do not add server credentials or private
user data to this repository. The Supabase frontend configuration may contain
only a project URL and publishable key.
